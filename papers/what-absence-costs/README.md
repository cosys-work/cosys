# What Absence Costs

LaTeX sources of *What Absence Costs*, a paper in social ontology on which social facts need an
authority behind them and which anyone holding the right records can settle alone. It follows
*Collaboration Is Composition* ([doi:10.5281/zenodo.24026645](https://doi.org/10.5281/zenodo.24026645)),
whose Lean proofs are in `proofs/`.

- `what-absence-costs.tex` is the main file; each section is in `sections/`.
- `refs.bib` holds the references, author-date.

Build with `make` (pdflatex and bibtex). `make anon` builds the copy for double-anonymized review.
